# AI Coding Agent

AI coding agent seperti Claude Code, Codex, atau Cursor mengenal Laragon dan XAMPP dari data
latihannya, tetapi belum pernah mendengar Rezure. Di mesin yang punya keduanya, agent yang
menjalankan `where php` atau melihat isi `C:\` cenderung mencari konfigurasi Laragon untuk
menjelaskan bagaimana proyekmu dilayani, dan salah menyimpulkan.

Rezure memperbaikinya dengan menyimpan deskripsi singkat yang selalu terbaru tentang setup-mu di
tempat yang dicari agent.

## Apa yang ditulis Rezure {#what-rezure-writes}

Tiga file di folder rumah Rezure, `C:\rezure`:

| File | Isi |
| --- | --- |
| `AGENTS.md` | Kondisi mesin ini saat ini: versi PHP aktif, database (engine, versi, alamat, dan login), LocalDB dan PostgreSQL kalau terpasang, port web dan email, dan tabel setiap proyek dengan URL, folder, framework dan folder yang dilayani (atau "dev server on :4400" untuk proyek JavaScript), serta versi PHP (ditandai "pinned" kalau dikunci). Plus aturan di bawah. |
| `CLAUDE.md` | Satu baris, `@AGENTS.md`, supaya Claude Code memuat file di atas. |
| `docs\how-rezure-works.md` | Panduan lengkap: layanan dan port, struktur folder, proyek, Nginx, PHP, setiap database, Mailpit, nilai `.env` Laravel, Node dan Composer, berbagi, dan berdampingan dengan Laragon dan XAMPP. |

Rezure menulisnya saat dijalankan dan mengecek setiap 60 detik selama berjalan, menulis ulang
`AGENTS.md` hanya saat memang ada yang berubah: proyek baru, versi PHP yang diganti, database yang
dipasang. Tidak ada pengaturan untuk ini.

**Rezure tidak pernah menulis ke folder proyek atau konfigurasi milik agent.** Dan file di salah
satu path itu yang tidak dibuat Rezure (tidak punya baris pertama `<!-- Generated by Rezure`)
dibiarkan, jadi `C:\rezure\CLAUDE.md` milikmu sendiri aman.

File-file ini tetap di mesinmu. Isinya path lokal dan login database, itulah sebabnya file-file
ini ada di folder Rezure dan tidak di tempat lain.

## Aturan yang diberikan ke agent {#the-rules-agents-are-given}

Selain fakta, `AGENTS.md` memberi tahu agent cara bersikap di mesin Rezure, kira-kira:

- Anggap Rezure sebagai dev server untuk proyek di `C:\rezure\www` atau yang tercantum di
  `AGENTS.md`. Jangan mencari konfigurasi Laragon atau XAMPP.
- Pakai `http://<project>.test` untuk URL dan `127.0.0.1` untuk database. Jangan mengharapkan
  HTTPS.
- Taruh pengaturan PHP di `C:\rezure\etc\php\conf.d`. Jangan edit apa pun di bawah
  `C:\rezure\data` (dibuat otomatis), blok Rezure di file `hosts`, atau file JSON Rezure selama
  aplikasi berjalan.
- Cek `where php` dan `php -v` sebelum berasumsi PHP mana yang menjalankan sebuah perintah, dan
  jalankan `artisan`, `composer`, dan `npm` dari terminal proyek.
- Framework proyek menentukan folder yang dilayani Nginx. Kalau salah, minta kamu menggantinya dari
  badge framework; framework yang tidak dikenal Rezure masuk ke `C:\rezure\etc\frameworks.json`.
  Lihat [Framework](/id/guide/frameworks).
- Proyek yang ditandai "dev server" dilayani oleh prosesnya sendiri di port yang tercantum di
  tabel. Minta kamu menjalankan atau menghentikannya dari Rezure (**Open**, atau **Projects → Dev
  servers**), dan jangan menjalankan salinan kedua di port itu. Lihat
  [Dev Server](/id/guide/dev-servers).
- **Minta kamu** untuk menjalankan atau menghentikan layanan, mengganti versi, menyinkronkan hosts,
  atau mengubah ekstensi di aplikasi Rezure, alih-alih mematikan `nginx.exe` atau `php-cgi.exe`,
  menjalankan `initdb`, atau memasang paket Microsoft sendiri.

## Claude Code {#claude-code}

Claude Code membaca `CLAUDE.md` dari setiap folder induk tempat ia dijalankan. Sesi di proyek di
bawah `C:\rezure\www` karena itu memuat `C:\rezure\CLAUDE.md`, dan lewat itu `AGENTS.md`, **tanpa
perlu setup apa pun**.

Proyek **tertaut** ada di luar `C:\rezure`, jadi tidak ada yang mengarahkan Claude Code ke sana dari
dalamnya. Untuk mencakup semua proyek sekaligus, tambahkan baris ini ke `%USERPROFILE%\.claude\CLAUDE.md`
tingkat user-mu:

```
@C:\rezure\AGENTS.md
```

Atau tambahkan baris yang sama ke `CLAUDE.md` milik satu proyek.

## Agent lain {#other-agents}

Agent yang membaca file `AGENTS.md` bisa diarahkan ke milik Rezure dengan cara yang sama: rujuk
`C:\rezure\AGENTS.md` dari file instruksi agent itu, atau dari `AGENTS.md` proyek. Untuk sekali
pakai, kamu juga bisa langsung bilang ke agent: "This machine uses Rezure; read
`C:\rezure\AGENTS.md` first."
